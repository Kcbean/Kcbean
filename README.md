## Academic Projects

### [Anime Recommendation System](https://github.com/Kcbean/anime_recommendation_system)

Collaborative academic project using MyAnimeList metadata and more than 24
million user-rating interactions. The project compared item-based collaborative
filtering, TF-IDF content filtering, truncated-SVD matrix factorization, hybrid
ranking, and K-means user segmentation using Precision@10, Recall@10, NDCG@10,
and catalog coverage.

### [Brain MRI Segmentation Prototype](https://github.com/Kcbean/brain_tumor_classification)

My segmentation contribution within a four-person academic capstone. I indexed
4,793 paired MRI images and masks, examined tumor-mask coverage, constructed a
TensorFlow `tf.data` pipeline, and validated an encoder-decoder segmentation
workflow through Dice-based smoke tests. The repository states separately which
classification work belonged to the wider team.
